**Date:** 2026-07-28 · **Tag:** `meridian-p1.0.5` (annotated)
**Contents:** PRs #38 (`0011`), #42 (`0012`, CP5a), #43 (`0013`, CP5b)
**Research baseline:** `eval-baseline-v3` — unchanged, and unaffected by construction

## What this release is

Three migrations that only make sense together: row-level security on the control plane,
cross-workspace foreign-key references made impossible, and clearance resolved through
`membership` — which is what allowed `principal` itself to be scoped.

`0011` alone could not scope `principal`: the correct policy is membership-derived, and
`membership` turned out to be an empty table that nothing populated. `0013` is what makes
`0011` complete. Releasing them separately would have published a documented half-fix as a
finished one.

security behaviour".

## Rules in force from this tag

- The tag is immutable and never moves. All future work builds *on* it.
- Migrations `0011`–`0013` are frozen. Any change to them is a new migration, not an edit.
- Fix only real, reproduced bugs against this baseline. No refactors, no churn.
- The next commit on `master` is either a genuine bug fix versus `meridian-p1.0.5` or the
  first accepted item of the next checkpoint. Nothing in between.

## Known limitations carried forward

Stated so they are not rediscovered as surprises:

1. **`app.workspace_id` is an ordinary GUC.** `callosum_app` can set it to any value, so RLS
   throughout this system is a guardrail against *application bugs*, not a hard boundary
   against a compromised runtime role. This release does not change that.
2. **Composite-FK protection covers one relationship of ten.** The other nine tenant-scoped
   foreign keys rely on an RLS-scoped existence check in the domain module — a real defence,
   but by convention rather than construction. Tracked in **#41**, deliberately not expanded
   into this release.
3. **`principal.clearance` still exists**, retained as a deprecated bootstrap seed because it
   is declared in the frozen `schema/postgres.sql`. It is demoted with a `COMMENT ON COLUMN`
   and no longer read for any access decision.
